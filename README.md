# XeGhép247

Nền tảng ghép hàng hóa, ghép hành khách liên tỉnh và ghép ghế du lịch tại Việt Nam.

Kiến trúc: Next.js static export, Tailwind CSS, Cloudflare Pages, Cloudflare Workers, Supabase PostgreSQL/PostGIS. Ưu tiên gói miễn phí, không tự kích hoạt billing.

GitHub Pages chỉ xuất tài liệu kỹ thuật; không triển khai ứng dụng mẫu công khai tại /demo/. Mã nguồn và dữ liệu fixture được giữ phục vụ phát triển và kiểm thử nội bộ. Ứng dụng thực tế chỉ mở giao dịch sau khi kết nối backend, xác thực, cơ sở dữ liệu và nghiệm thu an toàn.
