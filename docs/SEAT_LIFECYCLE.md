# Seat lifecycle draft
Trusted backend only; actor UUID must come from verified auth. Hold 10 minutes, same-seat retry returns existing deadline, cancellation idempotent. Trip row lock serializes writers using these functions; exclusion constraint prevents overlapping seat segments. available_seats is treated as configured segment capacity, not decremented per booking. Expiry cleanup occurs on next valid hold, not scheduled. Confirmation, baggage limits, multi-session tests, refund policy, and real Supabase verification remain pending. Do not expose service credentials or accept actor IDs from clients.
